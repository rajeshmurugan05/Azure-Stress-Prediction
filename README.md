# Azure-Based Stress Prediction using Automated Machine Learning

This project was developed as part of the **Intelligence Engineering and Infrastructure** module during my Master’s degree.

The objective of this coursework was to analyse human activity and real-time data to evaluate **stress and anxiety symptoms** using **Microsoft Azure Automated Machine Learning (AutoML)**.

## Objective

To demonstrate the use of cloud-based AI infrastructure for stress prediction by leveraging Azure Automated ML for model training, evaluation, and comparison without writing custom machine learning code.

## Platform and Tools

- Microsoft Azure  
- Azure Automated Machine Learning (AutoML)  
- CSV dataset (uploaded in the `data/` folder)  
- Visual outputs generated by Azure ML  

## Dataset

The dataset used for this project is stored in: Data/ 


It contains human activity–related features used to predict stress levels.  
The dataset does not include any personal identifiers and is safe for academic and portfolio use.

## Methodology

1. Dataset uploaded to Azure Machine Learning Studio  
2. Automated ML configured for stress prediction  
3. Multiple models trained and evaluated automatically  
4. Best-performing model selected based on evaluation metrics  
5. Results analysed using Azure-generated visual outputs  

## Outputs

Visual results produced by Azure Automated ML are stored in the following folder: Output/

These include:
- AutoML pipeline screenshots  
- Model evaluation metrics  
- Confusion matrices and charts
